基于 `ZFQ/大纲.md`（终审版 v3）实现。入口：双击打开 `index.html`，或部署到任意静态服务器。
游戏内容与素材只取自本目录（大纲 + assets），不引用任何外部文件夹。

## 玩法机制

1. **搜索框推进谜题**：页面顶部保留“响石旅行社”前台导航（首页/线路介绍/关于我们/
   客户评价/订单查询），这些公开页面可以直接点。但要推进谜题（直播存档、关键帧、
   机密档案、预言、日志等）必须把关键词输入搜索框并回车（或点“搜索”）。
   页面里的**加粗变色**文字只是检索提示，本身不可点击——把提示词抄进搜索框才是玩法。
2. **关键词即线索**：不是每个加粗词都有对应页面，搜不到会进入真正的 404 页；
   部分加粗词（如订单号 `SA11001215-???`）本身就意味着线索还不完整。
3. **两套隐藏文字**：
   - 404 提示页：白色文字藏在白色区块里，按 `Ctrl+A` 全选可见（页面有提示）。
   - 古树页：树皮刻痕记录区有与背景完全同色的文字，只能靠“全选”习惯发现（无提示）；
     其中“尸体”二字藏于铭文内，选中可见并带有抖动效果。
4. **进度页脚**：所有主线页面页脚显示 XX/14；动态中心与隐藏页不占进度。
5. **少数非关键词交互**：首页“最新动态”条目可点击进入动态中心；404 页提供“返回首页”；
   结局页的左右按钮是剧情抉择。这些不影响谜题本身。

## 测试要点

- 用 Chrome / Edge / Firefox 打开 `index.html`（file:// 或 http:// 均可，页面间跳转为普通链接）。
- 无背景音乐（素材中的 BGM 已移除），页面不加载任何音频。
- 视觉阶段：01–03 米白拟真 → 04 过渡 → 05–06 灰化+噪点 → 07–11 深灰蓝 →
  12–14 纯黑+红警戒。
- 特技：`frame_0325.html` 与 `lost.html` 加载后飘黑雪；`lost.html` 画面渐暗。
- 未先完成订单验证就访问 `livestream.html` 会看到“信号站景点解说”；
  在订单页输入 `SA11001215-325` 完成验证后，再于顶部搜索栏输入 `756`（或“直播存档”）即可解锁直播存档。
- 重置/恢复进度：不需要存档系统，清空浏览器会话存储（sessionStorage）即可恢复初始状态。

## 已知边界

- 本地 `file://` 下 sessionStorage 一般可用；若个别浏览器禁用，仅影响“直播解锁”状态，
  可改用 `livestream.html?archive=1` 直接查看。
- 文案中的日期、人物与事件均为《明日方舟》世界观同人创作，与现实无关。
