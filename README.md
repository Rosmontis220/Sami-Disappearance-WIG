# 知名主播萨米失联事件

《响石旅行社 · 萨米专区》网页解谜游戏（WIG）——一次关于“零失联记录”的调查。

知名主播周符卿报名了响石旅行社的萨米冰原探险直播行程。1100.12.15 凌晨，直播信号在 03:25 突然中断。行程宣称顺利结束、客户平安返回——可那场直播的存档，为什么找不到？

## 线上地址

<https://rosmontis220.github.io/Sami-Disappearance-WIG/>

## 玩法

- 站点主体是一家看似正常的旅行社官网：首页、线路介绍、关于我们、客户评价、订单查询都可以直接点击。
- 但真正的内容不会摆在你面前。页面里那些加粗变色的词只是检索提示——请把它们输入站内搜索框，回车或点击“搜索”。
- 页面中不存在可点击的关键词链接；搜对了就推进，搜错了只会得到 404。
- 藏在页面里的其他线索，需要你拖选、全选甚至“不小心”看到。
- 事件有两种结局。你的选择，决定真相会不会被埋进雪里。

## 本地运行

整个游戏是纯静态站点，不需要构建步骤。直接打开 `index.html`，或在项目目录启动任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。
